# pendaftaran mahasiswa baru dengan React

## Halaman

1. Halaman Home
2. Halaman About
3. Halaman PMB
4. Halaman Contact

## Materi Terkait

* React Component
* React Props
* React Event
* React Conditional
* React List
* React Form
* React Form Submit
* React Router
* React Lazy Loading dan Suspense
* React useState
* React useEffect
* React useContext
* React useRef
* React useReducer
* React useCallback
* React useMemo

## Fitur

* Form pendaftaran 3 langkah (useReducer)
* Notifikasi global (useContext)
* Pencarian, filter, dan urutan data (useMemo)
* Kursor otomatis ke Nomor Pendaftaran (useRef)

## Cara Menjalankan

```bash
npm install
npm run dev
```
